# RozetkaPay PayParts - Языковые файлы

## Включенные языки

### Украинский (uk_UA)
- `rp-payparts-uk_UA.po` - исходный файл перевода
- `rp-payparts-uk_UA.mo` - скомпилированный файл для WordPress
- `rp-payparts-uk_UA.json` - JSON для JavaScript переводов

### Русский (ru_RU)  
- `rp-payparts-ru_RU.po` - исходный файл перевода
- `rp-payparts-ru_RU.mo` - скомпилированный файл для WordPress
- `rp-payparts-ru_RU.json` - JSON для JavaScript переводов

### Шаблон (POT файл)
- `rp-payparts.pot` - основной шаблон для создания переводов

## Установка

1. Загрузите файлы в директорию `/wp-content/plugins/rozetkapay-payparts/languages/`
2. WordPress автоматически определит и применит переводы на основе настроек языка

## Структура переводов

### Основные разделы:
- **Административная панель** - настройки, меню, уведомления
- **Frontend интерфейс** - формы оплаты, сообщения пользователю
- **Валидация** - ошибки и предупреждения
- **Email уведомления** - шаблоны писем
- **JavaScript интерфейс** - динамические элементы

### Ключевые переводы:

#### Методы оплаты
- `Оплата частинами` → `Оплата частями` (RU)
- `Прийом платежів частинами` → `Прием платежей частями` (RU)

#### Настройки
- `Налаштування API` → `Настройки API` (RU)
- `Дозволені банки` → `Разрешенные банки` (RU)
- `Мінімальна/Максимальна сума` → `Минимальная/Максимальная сумма` (RU)

#### Интерфейс пользователя
- `Оберіть банк` → `Выберите банк` (RU)
- `Розраховуємо...` → `Рассчитываем...` (RU)
- `грн/міс` → `грн/мес` (RU)

#### Склонения
Украинский/Русский:
- `місяць/місяці/місяців` → `месяц/месяца/месяцев`
- Правильные plural forms для обоих языков

## Обновление переводов

### Для редактирования .po файлов рекомендуется использовать:
- **Poedit** - графический редактор переводов
- **WordPress CLI** - `wp i18n make-pot`
- **Текстовый редактор** - для быстрых правок

### Компиляция после изменений:
```bash
# Украинский
msgfmt -o rp-payparts-uk_UA.mo rp-payparts-uk_UA.po

# Русский  
msgfmt -o rp-payparts-ru_RU.mo rp-payparts-ru_RU.po
```

### Генерация нового POT файла:
```bash
wp i18n make-pot . languages/rp-payparts.pot
```

## Добавление нового языка

1. Скопируйте `rp-payparts.pot` 
2. Переименуйте в `rp-payparts-{locale}.po`
3. Переведите все строки
4. Скомпилируйте в .mo: `msgfmt -o rp-payparts-{locale}.mo rp-payparts-{locale}.po`
5. Создайте JSON файл для JavaScript переводов

## Контекст переводов

### Text Domain
Все переводы используют домен: `rp-payparts`

### Функции локализации
- `__()` - базовый перевод
- `_e()` - перевод с выводом
- `_x()` - перевод с контекстом
- `_n()` - перевод с множественным числом
- `esc_html__()` - безопасный HTML перевод

### Плейсхолдеры
- `%s` - строковые значения (названия банков, суммы)
- `%d` - числовые значения (периоды, количество)

## Тестирование

### Проверка загрузки переводов:
1. Смените язык WordPress в настройках
2. Проверьте админ-панель плагина
3. Протестируйте frontend формы
4. Убедитесь в корректности JavaScript переводов

### Функции отладки:
```php
// Проверка активного языка
echo get_locale(); // uk_UA, ru_RU

// Проверка загрузки текст-домена
echo is_textdomain_loaded('rp-payparts') ? 'Loaded' : 'Not loaded';

// Тест конкретного перевода
echo __('Оплата частинами', 'rp-payparts');
```
